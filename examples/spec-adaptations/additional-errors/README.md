# Portable additional-errors fixture

Adapted from jsonforms-extended-spec commit 7c354f4f03417c37d91080fcbd169561bce66cd6, example `additional-errors`. This fixture keeps the server-owned field error action, per-value clearing, schema validation, and English/Bulgarian messages. Monaco language-service tabs and editor-specific publication are excluded because the native port does not use Monaco. The original source fixture remains the provenance reference.
