# Extended-spec verification task manifest

This manifest maps the [extended-spec plan](extended-spec-plan.md) to executable gates. A green compile task proves source compatibility only; it does not prove UI interaction on that target. Record the command, revision, exit code, report and environment in [verification-log.md](verification-log.md) when a gate runs. Keep unsupported profiles explicit in [renderer-capabilities.md](renderer-capabilities.md).

Run focused tasks after a local change. Run the applicable module suites and host gates at an integration milestone and for release. Check `df -h .` before browser executables or native linking; reuse Gradle outputs and do not clean by default.

Targeted `./gradlew help --task :examples-compose-android:assembleDebug` and `help --task :examples-compose-android:connectedDebugAndroidTest` confirm those Android tasks exist. A broad `:examples-compose-android:tasks --all` currently fails while creating Compose Preview tasks because its debug resource and release unit-test requirements differ; use targeted task help until that tooling path is resolved. This inventory failure does not substitute for running either Android gate.
