# Structured option merge policies

These policies describe the Kotlin resolvers. Local UI-schema options are JSON values; form config is host-provided. An absent value may inherit a default, while an explicitly authored structured value follows the policy in its row. Resolvers read their sources without modifying them.

| Option | Resolution policy | Implementation |
| --- | --- | --- |
| Layout `gap`, `gridColumns`, `wrap` | Each top-level field resolves from the element, then `config.jsonformsExtended.layoutDefaults`, then its built-in default. A child's `options.layout` is its own object and does not inherit sibling layout fields. | `resolveLayoutSizing`, `resolveLayoutItemSizing` |
| Dialog `width`, `height`, `maximizable`, `draggable`, `resizable` | Each field resolves from the selected local dialog object, then `config.jsonformsExtended.dialog`, then its built-in default. A local invalid field does not borrow the global field. Flags require Boolean values; dimensions accept positive numeric pixels or supported unit strings. | `resolveDetailDialogOptions` |
| Collection `pagination` | Choose the whole local value, else the collection-specific config value, else the default. Fields from different levels do not merge. Explicit Boolean false disables pagination. | `resolveCollectionPagination` |
| Array `rowDetail` | Read the whole object from the array Control's local options. There is no global row-detail merge. Its optional `dialog` object is later resolved by the dialog field policy above. | `resolveArrayRowDetailOptions`, `resolveDetailDialogOptions` |
| Table `cells` | Select the local cell object by field name; absent cells are not synthesized from config. For a cell dialog, resolve its object through the dialog field policy. Type indicator uses cell, then collection, then form value. | `resolveArrayTableCellOptions`, `resolveArrayTableCellTypeIndicator` |
| Table required marker | Resolve `hideRequiredAsterisk` from cell, then collection, then form config. Only typed Booleans participate; a quoted cell value does not block a typed collection value. | `tableColumnHeaderLabel` |
| Table `columnDefs` | Use native `agGridOptions.columnDefs` only when AG Grid is requested and the native key is present; otherwise use local portable `columnDefs`, then automatic schema columns. An explicit empty array means an actions-only table. | `resolveArrayTableColumnDefs` |
| Table dynamic label summary | The form-wide gate is `config.jsonformsExtended.dynamicValues.enabled`. Only a typed true permits declared row/root interpolation; there is no local gate merge. | `resolveTableLabelSummary` |
| Composite dialog actions | Resolve each action flag or label from cell, then collection, then form config. An explicitly authored false stays false. | `resolveCompositeDialogActions` |
| Tuple presentation | Resolve `vertical` and `showBorder` individually from local tuple options, then `config.jsonformsExtended.tuple`, then defaults. Generic layout config does not participate. Quoted Boolean strings do not override typed defaults. | `resolveTuplePresentation` |
| Conditional object fields | The local `conditionalFields` Boolean takes precedence over `config.jsonformsExtended.conditionalFields`, then false. The projected schema keeps the original validator schema and diagnoses a malformed Boolean `if` value instead of selecting a branch. | `conditionalFieldsEnabled`, `projectConditionalObjectFields` |
| Choice autocomplete and inline error filter | The local choice `autocomplete` Boolean overrides the host default; the error filter reads the applied option value. Quoted Boolean strings do not activate either feature. | `choiceAutocomplete`, `filterControlErrorsBeforeTouch` |
| AG Grid native pagination overrides | Explicit native fields override portable pagination individually after portable whole-value selection. Quoted Boolean `pagination` and `paginationPageSizeSelector` values are ignored. | `applyAgGridPaginationOverrides` |

Focused resolver tests cover dialog field precedence, pagination whole-value selection, row-detail defaults, tuple and conditional-field selection, and table-cell behavior. `OptionMergeInvariantTest` checks source identity and content after layout and dialog resolution. The broader inventory of structured options and mounted target behavior remains in the requirement ledger.
